# To-Do

[English](README.md) · [Русский](README.ru.md)

Простой сервис списка дел на HTML, CSS и JavaScript.

## Возможности

- Добавление задач через форму
- Редактирование, дублирование и удаление задач
- Чистые HTML, CSS и JavaScript, без сборки

## Начало работы

Откройте `index.html` в браузере.

## Структура проекта

- `index.html` — разметка страницы
- `index.js` — логика задач
- `index.css`, `blocks/` — стили
- `fonts/`, `images/` — ресурсы
