# To-Do

[English](README.md) · [Русский](README.ru.md)

A simple to-do list web app built with HTML, CSS and JavaScript. The interface is in Russian.

## Features

- Add tasks through a form
- Edit, duplicate and delete tasks
- Plain HTML, CSS and JavaScript, no build step

## Getting Started

Open `index.html` in a browser.

## Project Structure

- `index.html` — page markup
- `index.js` — task logic
- `index.css`, `blocks/` — styles
- `fonts/`, `images/` — assets
